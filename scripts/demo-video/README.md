# 데모 움짤 만들기

커뮤니티·README용 기능 소개 움짤(움직이는 webp)을 만드는 도구. 커서 없이 녹화한 화면 위에 큰 커서·클릭 물결을 얹고, 카메라 확대·이동을 부드럽게 넣는다. 확장 zip 에는 포함되지 않는다.

결과물 (`assets/raw/`, gitignore):

| 설정 | 결과 | 내용 |
|---|---|---|
| `configs/box.js` | `box-demo.webp` | 샘플 저장 → 박스에서 불러오기 |
| `configs/calc.js` | `calc-demo.webp` | 계산기 "내 파티" 공격·수비 자동 입력 |
| `configs/speed.js` | `speed-demo.webp` | 스피드 패널 호버 → 스피드표 펼치기 |
| `configs/copy.js` | `copy-demo.webp` | 파티 텍스트 복사 → 메모장 붙여넣기 (녹화 2개 이어 붙임) |

## 준비

- **ffmpeg** (`winget install Gyan.FFmpeg`). 새 셸에선 PATH 로 잡힌다. 안 잡히면 `FFMPEG` 환경변수에 `ffmpeg.exe` 전체 경로를 넣는다.
- Node 18+.

## 녹화

| 항목 | 값 |
|---|---|
| 도구 | Windows 게임 바 (`Win+Alt+R`), 크롬 창 녹화 |
| 커서 | **끈다** — 설정 → 게임 → 캡처 → "녹화할 때 마우스 커서 캡처" 끄기 (커서는 나중에 얹음) |
| 크롬 확대 | 125% (2560×1440 모니터 기준. 녹화본 1920×1044, 위 64px = 탭·주소창) |
| 동작 | 클릭 전 0.5초 정도 멈춤, 마우스 올림 표시(테두리)가 뜨게 잠깐 올려두기 |
| 저장 | `assets/raw/` (gitignore) |

같은 확대·창 크기로 녹화하면 `box.js` 의 좌표(카드·박스 버튼 위치 등)를 그대로 참고할 수 있다.

## 순서

1. **클릭 시점 찾기** — 0.25초 간격 타임스탬프 밀착 인화:
   ```bash
   node scripts/demo-video/render.js sheet assets/raw/<녹화>.mp4 4 780:560:570:140
   ```
   (`fps`, `crop=w:h:x:y` 는 선택. 결과 = `scripts/.cache/demo-video/sheet/`)
   커서가 안 보이므로 화면 반응(선택 테두리·말풍선·창 열림)으로 클릭 시각을 잡는다. 반응 0.1~0.2초 전이 클릭.
2. **좌표 찾기** — 필요한 순간을 원본 크기로 한 장 뽑아 확인: `ffmpeg -ss 12 -i <녹화> -frames:v 1 f.png`
3. **설정 파일** — `configs/box.js` 를 복사해 `points`·`cursor`·`clicks`·`views`·`camera`·`trim` 을 채운다.
4. **렌더** — `node scripts/demo-video/render.js configs/<이름>.js`

## 설정 옵션 (필요할 때만)

| 키 | 용도 | 예 |
|---|---|---|
| `cuts: [[시작, 끝]]` | 기다린 구간 잘라내기. 카메라·커서·클릭 시간은 **원본 초 그대로** 적으면 됨 | `speed.js` |
| `cursorScreen: 24` | 커서를 카메라 뒤(출력 화면)에 그림 → 확대와 무관하게 크기·화면 위치 고정 (값 = 출력 px 높이). 화면이 통째로 바뀌는 장면에서 커서를 가만히 두고 싶을 때 | `copy.js` |
| `segments: [{...}, ...]` | 녹화 여러 개 이어 붙이기. 항목마다 `input`·`trim`·`base`·`views`·`camera`·`points`·`cursor`·`clicks`, 공통값(`size`·`fps`·`cursorScreen`)은 바깥 | `copy.js` |

주의:
- **카메라 이동은 `cuts` 구간 전에 끝나야 함** — 이동 도중을 잘라내면 순간이동처럼 튐.
- **호버 싱크**: 미리보기·테두리가 뜨는 프레임을 0.05초 단위로 찾고, 커서가 그 직전에 대상의 **경계를 넘도록** 이동 시작을 역산 (가운데에 멈출 때가 아님). 계산 예 = `speed.js` 주석.
- **화면 전환**(탭 이동 등)은 앞뒤 프레임 시각을 찾아 그 사이에서 카메라를 0.001초 만에 넘김.
- 녹화를 이어 붙일 때 커서 위치 맞추기 = 앞 화면에서 커서의 화면 비율(x/폭, y/높이)을 뒤 화면 view 에 곱해 원본 좌표를 구함 (`copy.js` `hold`).
- 메모장 등 다른 창은 따로 녹화 (게임 바 = 맨 앞 창 하나만 녹화). 글자를 키워 녹화하면 확대 없이 선명.

## 정해 둔 값

`render.js` 의 `STYLE` (모든 움짤 공통):

| 항목 | 값 | 비고 |
|---|---|---|
| 커서 | 흰 화살표 높이 28px, 윤곽 = 높이/20 (≈1.4px) | 원본 녹화 픽셀 기준. 카메라 확대에 따라 같이 커짐 |
| 클릭 | 0.15초 동안 24px 로 눌림 + 핑크(`#e4007f`) 물결 반지름 4.5→25px, 0.4초 | 물결은 커서 크기에 맞춰 줄인 값 |
| 이동 곡선 | easeInOutCubic | 커서·카메라 공통 |
| webp | 품질 75, 무한 반복 | |

설정 파일(`box.js`) 쪽 관례:

- **화면비 3:2 (720×480), 20fps** — 세로로 긴 화면은 별로라 가로로. 사이트 "전체"는 헤더~#4 카드 정도면 충분.
- **카메라 이동 1.1초**, 커서 이동 0.7~1초. 커서는 마우스 올림 표시가 뜨기 직전에 도착.
- **흐름**: 전체 화면 → 클릭 대상 쪽 확대 → (다음 대상 쪽으로 이동, 덜 확대) → 끝에 전체 화면으로 축소 후 2초 유지 (반복 재생 시 시작 화면과 이어짐).
- 앞쪽 대기는 `trim` 으로 자른다 (첫 동작 1초 전부터).
- 원본 해상도가 낮으니 확대는 1.8배(`w` 540) 정도까지.
